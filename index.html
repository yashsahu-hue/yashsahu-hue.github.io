Making inference cheap enough to run anywhere it needs to.

I'm Yash Sahu. My research finds the best place — on-device, at the edge, or in the cloud — for a neural network to run, and adapts that decision as conditions change, so LLMs and SLMs stay fast and usable on resource-constrained hardware.

About

I'm a PhD scholar in the Department of Computer Science and Engineering at IIT Gandhinagar, advised by Prof. Anirban Dasgupta. My work sits at the intersection of systems and machine learning: I study how to run AI inference efficiently when compute, memory, and network conditions can't be taken for granted.

Concretely, that means adaptive split computing — dynamically choosing where a model's computation should happen across a device, one or more edge nodes, and the cloud — and efficient LLM/SLM deployment through quantization, LoRA, and knowledge distillation. I use reinforcement learning (PPO) and surrogate cost models to make these decisions in real time, as system conditions shift.

Before the PhD, I completed my B.Tech in Computer Science and Engineering (Cyber Security) where I built a foundation in data structures, operating systems, computer architecture, and security.

Selected projects

Adaptive Split Computing using Reinforcement Learning

Python · PyTorch · PPO

An RL-based inference optimization framework that dynamically selects model split points from system state and predicted inference cost — policy and value networks, PPO training, GAE, clipped objectives, and state-dependent action selection.

Efficient LLM/SLM Inference for Edge Devices

Python · PyTorch · Hugging Face

Quantization, LoRA/PEFT, and knowledge distillation for lightweight deployment, with a focus on how partitioning, communication overhead, and compute cost trade off against inference quality.

VakyaVed — Multilingual Speech Recognition
